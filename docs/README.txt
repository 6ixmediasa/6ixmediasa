PLATFORM DOCUMENTS — JUST DROP PDFs IN THIS FOLDER
==================================================

No code editing needed. Name the file after the page, and it appears.

NAMING RULE
  Start the filename with the page name, then a dash, then whatever you
  want the document called.

    vendra-overview.pdf         appears on /platforms/vendra
    vendra-technical-spec.pdf   appears on /platforms/vendra
    freshlane-brochure.pdf      appears on /platforms/freshlane
    tablo-overview.pdf          appears on /platforms/tablo

  The bit after the dash becomes the label on screen, so
  "vendra-technical-spec.pdf" shows as "Technical spec".

  A file named just vendra.pdf is labelled "Overview".

THE EIGHT PLATFORM NAMES
    vendra        freshlane     tablo         chalkline
    lendo         callout       waypoint      dispatch

  So a full set would be:
    vendra-overview.pdf
    freshlane-overview.pdf
    tablo-overview.pdf
    chalkline-overview.pdf
    lendo-overview.pdf
    callout-overview.pdf
    waypoint-overview.pdf
    dispatch-overview.pdf

MORE THAN ONE PER PLATFORM
  Add as many as you like. Tabs appear automatically above the viewer.
    vendra-overview.pdf
    vendra-pricing.pdf
    vendra-technical-spec.pdf

  Files named "overview" show first, then "brochure", then the rest
  alphabetically.

IT ALSO WORKS ON OTHER PAGES
  Same rule, using the last part of the web address:
    web-design-samples.pdf   ->  /websites/web-design
    branding-portfolio.pdf   ->  /design/branding
    about-company-profile.pdf ->  /about

IF A PLATFORM HAS NO PDF
  Nothing shows. The section only appears when a matching file exists,
  so a half-finished set never looks broken.

AFTER ADDING FILES
  In development the page updates on refresh.
  For a live site, rebuild and redeploy so the new files are picked up.

KEEP IN MIND
  Under about 5 MB each, or mobile users on data will give up.
  Anything in this folder is public — anyone with the link can open it,
  and Google can index it. Never put contracts, client pricing or
  confidential material here.
